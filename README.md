# Elisabeth Fidrmuc — academic website

Static personal website for GitHub Pages.

## Publish

1. Create a public GitHub repository named `lisafid.github.io`.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`.
4. The site will appear at <https://lisafid.github.io>.

## Photo

Save the supplied portrait as `assets/profile.jpg`. The site crops it responsively.
